# Project guidance

- Preserve the existing design, editorial content, URLs and client data unless the task explicitly changes them.
- Build page content with editable WordPress blocks and patterns. Prefer the project's installed block library when appropriate, and use core blocks where they fit.
- Maintain semantic headings, keyboard access, responsive layouts and meaningful image alternatives. Respect reduced-motion preferences.
- Treat AI-generated code and design as a draft: verify in the editor and on desktop and mobile, and test changes that affect behavior.
- Never commit credentials, customer data, uploads, private plugin packages or Composer authentication. Keep `composer.lock` synchronized with dependency changes.
- Do not deploy or modify a production database without the project owner's authorization and a verified backup and rollback plan.
